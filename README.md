## 这个仓库是什么
C9 自驱项目的第一周 MVP——一个单页产品落地页，用来验证"有没有人想要一个拍照点评书法的 AI 陪练"。

落地页包含：
- 价值主张（hero）
- 4 个核心功能
- 4 类目标用户
- 产品演示截图占位区（开发中）
- 早期用户登记表单（waitlist，目前为占位收集）

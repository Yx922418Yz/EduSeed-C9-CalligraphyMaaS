CORE FEATURES

它能帮你做什么

不是又一个"书法百科"，而是一个真的陪你动笔、给你反馈的练习搭子。

拍照评字

上传一张你手写的照片，AI 指出笔画、结构、间架哪里不到位，告诉你怎么改。

例字示范

选一个字，生成楷书、行书、钢笔等不同风格的示范，照着临，不用自己到处找帖。

记住你的进步

记录你练过的每个字和每次的问题，下周开课先读它——像我那个有记忆的本地 Agent 一样。

每日一字

每天推一个适合你当前水平的字，配上一段 3 分钟的引导，打开就能练。
